#  VidaFit Market

## Plataforma web de bienestar y comercialización de productos para humanos y mascotas

VidaFit Market es una aplicación web desarrollada como proyecto productivo del programa **Análisis y Desarrollo de Software (ADSO) del SENA**.

La plataforma está orientada a la gestión y comercialización de productos relacionados con el bienestar integral, permitiendo administrar productos saludables para personas y soluciones de cuidado para mascotas.

El sistema integra módulos administrativos y comerciales que facilitan la gestión de usuarios, productos, pedidos, devoluciones, recomendaciones y contenido informativo.

---

#  Objetivo del proyecto

Desarrollar una solución tecnológica web que permita optimizar los procesos de administración y comercialización de productos mediante una arquitectura organizada, facilitando la interacción entre usuarios, administradores y el sistema.

---

#  Funcionalidades principales

El sistema cuenta con los siguientes módulos:

##  Gestión de usuarios

- Registro de usuarios.
- Inicio de sesión.
- Administración de perfiles.
- Control de acceso al sistema.

##  Gestión de productos

- Registro de productos.
- Actualización de información.
- Consulta de catálogo.
- Administración de productos disponibles.

##  Gestión de pedidos

- Registro de pedidos.
- Consulta del estado de pedidos.
- Administración de compras realizadas.

##  Gestión de devoluciones

- Registro de solicitudes de devolución.
- Control y seguimiento de procesos.

##  Módulo de mascotas

- Gestión de información relacionada con mascotas.
- Administración de productos y servicios enfocados en animales.

##  Blog informativo

- Publicación de contenido relacionado con bienestar.
- Información para usuarios interesados.

##  Sistema de recomendaciones

- Sugerencias de productos según las necesidades del usuario o mascota .

##  Reportes

- Generación de información para apoyar la administración del sistema.
