# 🐾 VidaFit Market

## Plataforma web de bienestar y comercialización de productos para humanos y mascotas

VidaFit Market es una aplicación web desarrollada como proyecto productivo del programa **Análisis y Desarrollo de Software (ADSO) del SENA**.

La plataforma permite gestionar procesos de comercialización de productos orientados al bienestar integral, integrando un catálogo para usuarios interesados en productos saludables para personas y soluciones de cuidado para mascotas.

## 🎯 Objetivo

Desarrollar una solución tecnológica que facilite la administración de productos, usuarios y procesos comerciales mediante una arquitectura web organizada y escalable.

## 🚀 Funcionalidades

- Gestión de usuarios.
- Administración de productos.
- Catálogo de productos.
- Registro e inicio de sesión.
- Gestión de pedidos.
- Control de devoluciones.
- Módulo de mascotas.
- Blog informativo.
- Sistema de recomendaciones.
- Generación de reportes.

## 🛠️ Tecnologías utilizadas

### Backend
- C#
- ASP.NET Web API
- Entity Framework
- .NET

### Frontend
- HTML5
- CSS3
- JavaScript

### Base de datos
- SQL Server
